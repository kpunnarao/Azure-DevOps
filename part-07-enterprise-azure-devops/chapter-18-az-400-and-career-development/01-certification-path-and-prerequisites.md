# Certification Path and Prerequisites

## Credential path

As of this guide's review, Microsoft Certified: DevOps Engineer Expert requires:

1. Earn at least one prerequisite certification:
   - Microsoft Certified: Azure Administrator Associate, commonly earned through AZ-104; or
   - Microsoft Certified: Azure Developer Associate, commonly earned through AZ-204.
2. Pass AZ-400: Designing and Implementing Microsoft DevOps Solutions.

Verify the certification page before acting because Microsoft can change exams and prerequisite rules.

## Choose the prerequisite by real role

Choose the administrator path when your work emphasizes identity, governance, compute, networking, storage, monitoring, and operations. Choose the developer path when it emphasizes application design, SDKs, compute integration, data, messaging, security, and observability.

Do not choose only by perceived exam difficulty. AZ-400 assumes experience both administering and developing in Azure, with strength in at least one.

## Practical prerequisites beyond certificates

Before AZ-400, be able to:

- Navigate Azure identity/RBAC, networking, compute, storage, Key Vault, Monitor, and containers.
- Use Git fluently.
- Author/debug YAML and scripts.
- Build/test/package at least one application stack.
- Provision infrastructure with IaC.
- Explain HTTP, DNS, TLS, process, filesystem, and container fundamentals.
- Use Azure DevOps and understand GitHub equivalents/differences.
- Read logs, query telemetry, and respond to failure.

The capstone provides evidence; fill Azure administration/development gaps separately.

## Exam logistics

Official guidance currently states a score of 700 or greater is required to pass. Price depends on region. Use a personal Microsoft account for certification profile continuity rather than an employer-controlled account, following Microsoft's recommendation. Explore the official exam sandbox and request accommodations early if needed.

Role-based certifications expire unless renewed; Microsoft provides free online renewal assessment through Microsoft Learn under current policy. Set reminders and continue hands-on work.

## Ethics and security

Use only legitimate learning material and official practice assessments. Do not use exam dumps or reproduce protected questions. Dumps teach recognition, become outdated, violate rules, and do not create engineering judgment.

## Interview preparation

**AZ-104 or AZ-204 first?**  
Choose the one aligned to current duties and weakest foundation; both can support AZ-400.

**Does passing AZ-400 make someone expert?**  
It validates a defined knowledge/skills assessment. Expertise additionally requires production judgment, failure handling, communication, and sustained practice.

## Practical exercise

Build a prerequisite matrix across Azure administration and development. Mark demonstrated/partial/unknown, link evidence, and complete one lab from the weaker side before scheduling.
