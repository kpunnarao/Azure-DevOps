# Practice Assessments and Gap Analysis

[← AZ-400 Skills](02-az-400-skills-and-learning-paths.md) · [Chapter 18](README.md) · [Next: Interview Preparation →](04-scenario-based-interview-preparation.md)

## Assess to learn

Start with the official free Practice Assessment under realistic conditions, but do not memorize question positions. For every answer—correct or incorrect—explain why each option fits or fails, which constraint changes the choice, and how to verify it.

Practice scores are diagnostic, not a guarantee of exam performance.

## Gap log

| Field | Purpose |
|---|---|
| Objective/domain | Maps to official outline |
| Scenario and chosen answer | Preserves reasoning |
| Correct principle | What should guide decision |
| Root cause | Concept gap, misread, product confusion, memory, time |
| Official source | Verification |
| Hands-on action | Build/break task |
| Retest date | Spaced retrieval |
| Status/evidence | Demonstrated closure |

Root cause matters. “Wrong answer” is not a gap analysis.

## Study responses

- **Concept gap:** draw/explain model, then implement.
- **Product distinction:** create comparison table and lab both options.
- **Misread constraint:** underline identity, scope, trust, cost, downtime, and objective.
- **Troubleshooting gap:** inject failure and diagnose from evidence.
- **Memory gap:** spaced flashcards only for facts requiring recall.
- **Time pressure:** timed mixed scenarios after understanding improves.

## Readiness signals

- Consistent performance across several spaced attempts, not one repeated set.
- No domain masked by overall score.
- Explanations survive follow-up “why not the other option?”
- Capstone demonstrates high-weight objectives.
- Unknowns are resolved through current official docs.
- Adequate sleep/time/exam environment plan.

Stop repeated assessment when familiarity inflates scores. Use new scenarios and hands-on changes.

## Exam technique

Read objective and constraints first. Identify whether the question asks design, implementation, troubleshooting, lowest administration, lowest cost, strongest security, or minimal downtime. Eliminate answers violating scope or trust. Do not invent unstated requirements. Mark/review efficiently.

## Interview preparation

**Why did you choose this answer?**  
Respond with requirement, mechanism, tradeoff, failure mode, and verification—not “Microsoft recommends it.”

**How handle a changed feature?**  
State the assumption/date and consult current official documentation rather than bluff.

## Practical exercise

Take a baseline assessment, create at least 20 gap entries, implement five corrective labs, wait several days, then answer fresh scenarios and compare reasoning quality.
