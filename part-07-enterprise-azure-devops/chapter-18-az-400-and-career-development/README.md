Weights guide time allocation but do not make low-weight topics optional. Scenario questions combine domains.

## Readiness standard

You are ready when you can:

- Complete the capstone from a clean clone.
- Explain alternatives and tradeoffs without memorized slogans.
- Diagnose unfamiliar failures using first principles.
- Score consistently on current official practice assessments and explain every answer.
- Navigate relevant official documentation efficiently.
- Teach each domain and answer follow-up questions.
- Recognize where GitHub and Azure DevOps differ because the current exam covers both.
- Recheck the latest skills outline and update this repository.

## Study cycle

1. Baseline against objectives.
2. Build and break a lab.
3. Explain it from memory.
4. Answer scenario questions.
5. Review official documentation.
6. Log gap/root cause.
7. Rebuild weak capability.
8. Retest after spacing.
9. Teach it.
10. Schedule only when evidence is consistent.
