## Guided chapter lab

Create an enterprise blueprint for three product teams and one platform team. Include:

1. Organization/project/team/repository/area ownership.
2. Microsoft Entra groups and administrative separation.
3. Versioned CI and deployment paved roads with exception flow.
4. Microsoft-hosted, Managed DevOps Pool, or self-hosted agent decision.
5. Trust zones for PR, main CI, infrastructure, and production deployment.
6. Demand/queue model and capacity forecast.
7. Naming, tagging, retention, archive, and deletion catalog.
8. Extension and task allow/review process.
9. API automation identity, inventory reconciliation, and webhook reliability.
10. Monthly cost allocation, RTO/RPO, continuity exercise, migration plan, and DX scorecard.

## Completion criteria

You are ready for the capstone when you can explain every enterprise boundary, quantify agent capacity, prove an extension/API trust decision, run an exception process, and demonstrate that the platform improves team outcomes rather than shifting toil.
